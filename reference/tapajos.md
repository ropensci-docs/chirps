# Tapajós National Forest

Geometries for the Tapajós National Forest, a protected area in the
Brazilian Amazon

## Usage

``` r
tapajos
```

## Format

An object of class 'sfc_POLYGON' within the bounding box xmin: -55.41127
ymin: -4.114584 xmax: -54.7973 ymax: -2.751706

## Source

The data was provided by the Chico Mendes Institute for Biodiversity
Conservation (ICMBio) via <https://www.protectedplanet.net/en>
